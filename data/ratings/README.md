# Ratings

This directory holds the frozen rubric and the human-rating schema. Real human ratings are produced when the study runs; only a labelled synthetic fixture ships in the repo.

| File | Purpose |
|---|---|
| `rubric.yaml` | Frozen five-dimension rubric. |
| `ratings_*.jsonl` | One human rating per line. Produced by `pipeline/03_collect_human_ratings.py ingest`. |
| `ratings_SIMULATED.jsonl` | **SYNTHETIC demo fixture, not real ratings.** Generated by `code/scripts/generate_synthetic_ratings.py`; every line carries `"synthetic": true` and a `[SYNTHETIC DEMO]` critique. See [`../../demo/README.md`](../../demo/README.md). |

## Schema for `ratings_*.jsonl`

Each line is a JSON object with:

```json
{
  "figure_id":         "chem_complex_titration_curve",
  "rater_id":          "RX-007",
  "rater_role":        "domain_expert" | "screen_reader_user" | "sighted_fallback_with_sr_experience",
  "candidate_round":   4,
  "score": {
    "D1_factual_correctness":   4,
    "D2_information_sufficiency": 5,
    "D3_domain_accuracy":        4,
    "D4_hallucination":          5,
    "D5_conciseness":            4,
    "critique":                  "One paragraph of free-text critique."
  },
  "rendered_via_nvda": true,
  "timestamp":         "2026-04-23T14:05:00Z"
}
```

## Blinding

Raters do not see the critic's scores. Raters do not see the candidate's
generation model. The candidate text is presented either as text plus NVDA
audio (live mode) or as text plus a pre-rendered WAV file (offline mode).

## Coverage

Two raters score every calibration figure: a domain expert and a screen-reader
user. The `HumanRatingProtocol.budget_used()` helper reports, at any point in the
run, how many figures have reached two-rater coverage.

## Synthetic demo fixture

`ratings_SIMULATED.jsonl` is simulated placeholder data, not a collected rating.
It lets the pipeline run end to end before the real human study, exactly as the
code's test doubles do. No human produced these scores. The file is regenerated
by `code/scripts/generate_synthetic_ratings.py` and must never be cited or
presented as a result. The genuine ledger replaces it once the study runs.
