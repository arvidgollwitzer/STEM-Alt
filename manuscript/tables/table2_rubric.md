# Table 2. Five-dimension scoring rubric.

Each dimension scored 1–5 (Likert). D1, D2, D3 form the primary outcome.

| Dim. | Name                       | Definition                                                                                  |
|------|----------------------------|---------------------------------------------------------------------------------------------|
| D1   | Factual correctness        | Does the description correctly state what is visible in the figure?                          |
| D2   | Information sufficiency    | Does it contain enough information for a screen-reader user to reconstruct the figure's claim? |
| D3   | Domain accuracy            | Are technical terms used correctly within the figure's scientific domain?                    |
| D4   | Hallucination              | Does the description add content that is not in the figure? (5 = no invented content)         |
| D5   | Conciseness                | Does the description follow the DIAGRAM length guidance for its figure category?             |

## Primary outcome
mean(D1, D2, D3) per (figure, candidate) pair.

## Secondary outcomes
D4 and D5, reported per dimension. Krippendorff's α is reported per
dimension on the held-out split and on the pre-registered primary outcome.
